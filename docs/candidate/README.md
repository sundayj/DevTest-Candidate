# DevTest Candidate Tasks

This directory contains candidate-friendly versions of the DevTest interview tasks. These versions have been specifically designed for candidates and exclude implementation details, evaluation criteria, and other interviewer-specific content.

## Overview

The DevTest system includes 10 comprehensive tasks that evaluate different aspects of software development skills:

1. **Interactive Book Management Interface** - Frontend development with JavaScript/jQuery
2. **RESTful API Development** - Backend API design with Django REST Framework
3. **User Authentication & Authorization** - Security and user management systems
4. **Comprehensive Test Suite** - Testing methodologies and quality assurance
5. **Book Recommendation System** - System design and algorithm implementation
6. **Bug Hunt & Debugging Challenge** - Problem-solving and debugging skills
7. **Database Query Optimization** - Performance optimization and database skills
8. **Advanced Search Implementation** - Search algorithms and user experience
9. **Data Import/Export System** - Data processing and file handling
10. **Performance Monitoring & Caching** - System monitoring and optimization

## Task Structure

Each task file includes:

- **Overview**: Clear description of what needs to be built
- **Project Setup**: Instructions for getting the development environment running
- **Task Requirements**: Detailed requirements divided into core and optional features
- **Technical Considerations**: High-level guidance on implementation approaches
- **Submission Guidelines**: What to submit and how to organize the work
- **Helpful Resources**: Links to relevant documentation and resources

## What's Different from Interviewer Versions

The candidate versions have been cleaned up to remove:

- Detailed implementation guidelines with code examples
- Evaluation criteria and scoring rubrics
- Time management tips and common pitfalls
- Specific solution approaches and hints
- Interviewer notes and discussion points

## Usage Instructions

### For Candidates

1. Choose the task(s) assigned to you by your interviewer
2. Follow the project setup instructions in each task
3. Read through the requirements carefully
4. Implement the solution according to the specifications
5. Follow the submission guidelines for your deliverables

### For Interviewers

- Use the files in `docs/interviewer/` directory for the complete versions with implementation details
- These candidate versions can be shared directly with candidates
- The interviewer versions contain evaluation criteria and expected solutions

## Getting Started

Before starting any task, ensure you have:

1. The DevTest project running locally
2. Access to the development environment (Docker or DevContainer)
3. Understanding of the existing codebase structure
4. Familiarity with the models and data relationships

## AI Assistance Policy

You are welcome to use AI tools like ChatGPT, Claude, or similar assistants during your implementation. However, please note:

- **You must explain your thought process**: Document your reasoning for design decisions and implementation choices
- **Share your AI interactions**: If you use AI assistance, please include relevant chat logs or conversations in your submission
- **Understand the code**: Be prepared to explain and defend any AI-generated code during the interview discussion
- **Original thinking valued**: While AI can help with implementation, we're interested in your problem-solving approach and architectural decisions

This policy allows you to work efficiently while ensuring we can properly evaluate your technical skills and thought process.
